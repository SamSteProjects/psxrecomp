# Current encoded bank links

Open **Audio → Inspect sequence events → Edit sequence operands…**, select a positive-velocity Current note start, then **Inspect Current encoded bank links**. This read-only child inspector connects the reached Current note to its latest prior encoded program change on the same channel. It displays tone records whose explicit program operand and key range match that note, plus each candidate's bounded Current sample span and hash. **Save encoded bank link evidence** downloads the complete qualified metadata report.

The inspector decodes the composed Current native bank, including existing bank parameters and sample replacements. A local operand draft or reviewed Proposed sequence does not replace Current in this view. The summary identifies the note and program-change event, program slot's declared tone count, candidate count and Current bank hash. Packed page/row identities remain separate from program slot numbers. Unresolved sample operands remain visible. A standalone sequence has no colocated bank; a note without a prior encoded program change has an unknown initial assignment. No default program is assumed.

These are encoded source candidates. The tool does not infer packed-page ownership, active/unused tone selection, controller bank selection, percussion semantics, sustain, envelopes, pitch/rate or runtime instruments/residency. A declared program tone count does not prove which matching records are active. Native authoring and audio playback acceptance remain separate.

The exact `POST /api/audio-note-links` request binds asset ID, retail entry hash, resource source key, complete Current authoring key and reached note index. The response binds Current entry/sequence hashes, exact Current note and prior program event, and a source-qualified bank DTO. The client independently checks the note/program history against its qualified sequence and validates bank carrier pieces, tables, source operands, sample extents and hashes using the shared bank decoder. Current input changes withdraw results/download eligibility; busy state prevents download; closing or refreshing the parent releases the child. A closed child cannot publish a late response. Inspection and downloads issue no command, Save or Build.
