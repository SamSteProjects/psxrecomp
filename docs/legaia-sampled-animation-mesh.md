# Sample an external animation pose into native mesh geometry

Status: **partial backend milestone**, with synthetic qualification. The importer and SDK native command now accept an explicit `animation_pose` containing `animation_index` and `time_seconds`. HTTP routes, editor clip/time controls, retained-source/settings client support, actual retail Save/Open and normal Build acceptance are still pending. This is an intermediate part of the existing mesh-import workflow, not a completed separate editor tool or native animation system.

The selected external GLB clip is sampled at the declared time before the existing morph, weighted skin and node-transform pipeline converts positions and normal directions into native coordinates. Translation, rotation, scale and morph-weight channels support STEP, LINEAR and CUBICSPLINE. Rotation uses the existing shortest-arc/normalized interpolation implementation. Endpoint sampling clamps to the first/last key as specified by [glTF 2.0 animation sampling](https://registry.khronos.org/glTF/specs/2.0/glTF-2.0.html#animations). This produces one static geometry snapshot. It does not create native skeletal/morph animation, retargeting or runtime playback.

The explicit clip index is bounded to the existing 64-clip inventory; time and decoded key times are finite within 0–3600 seconds. Channels retain existing ownership/scene bounds. Selected channel input/output data must be nonsparse embedded FLOAT accessors, tightly packed/aligned, with increasing times and matching key counts; existing accessor/component budgets apply. Duplicate targets, matrix-bearing animated nodes, unsupported interpolation/extensions, invalid quaternion keys/results and malformed morph-weight ownership reject before mutation. Selected morph targets retain the existing eight-target limit and target order. Unselected scene channel ownership remains visible while its sampler payload is excluded. Unchosen clips do not alter the declared base node pose.

Importer inspection and mesh decoding share the same pose-qualified source list. Scope metadata records the selected clip/time, sampled channel identities/interpolation/key ranges and excluded channels alongside original activity ownership. Legacy calls without a pose keep their static-only guard and unchanged metadata contracts.

SDK mesh Review binds the normalized pose choice into its review key. Apply recomputes that review and refuses a changed time/clip. Original animated GLB bytes remain retained with the pose recipe through the existing mesh-source receipt and native ledger ownership. Retained-source validation replays that recipe to reproduce the complete candidate. No alternate project schema, source rewrite or replacement of imported provenance was introduced.
