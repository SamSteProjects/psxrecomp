## Editor workflow

Open the existing native mesh import dialog, enable **Sample animation pose**, choose a zero-based clip index and time, then upload the original GLB. Changing the clip/time invalidates Review. Use **Inspect animation pose** to qualify the new choice, then **Review mesh import** to compare Current and Proposed geometry before explicit Apply. The existing source scene, scale, rotation, origin, UV, primitive selection and donor/group choices continue to apply. One donor may import all supported primitives or one selected primitive. **Map section donors** carries the qualified pose into the existing section mapping editor. Each selected section uses its chosen native donor and UV set; object/group replacement rules remain enforced. The pose stays fixed for that mapped draft. To choose another clip/time, reopen the original mesh dialog, requalify the source and Review again.

Retained mesh sources download the original animated GLB and import settings JSON. Load the GLB before its settings. Recovery requalifies the declared clip/time against that exact source, restores the controls and source note, and requires fresh Review before Apply. The recipe carries the optional pose for single-donor and batch imports; existing static and batch recipe shapes remain supported. The existing proposed scene request forwards the same pose choice; an assembled-scene pose inspection was not exercised in this checkpoint.
