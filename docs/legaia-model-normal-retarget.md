# Object-wide normal-reference retargeting

Open an unposed model, choose **Edit model vectors**, select the object, choose **Normals** and select the Current source normal index. Expand **Retarget uses of this normal in this object**, enter another existing **Target normal index**, then **Preview normal retargeting**. This replaces matching stored references only within this object. Flat references serve every face corner; Gouraud references belong to their individual corner. Unlit packets have no normal operands and are ignored.

Preview first qualifies the complete Current-user report using the inspected model hash and project source key. The browser checks that every proposed reference-word change matches exactly one reported owner and the requested from/to values; omissions, duplicates, foreign offsets and hash inconsistencies reject. Current/Proposed object previews can show **Source normal directions**, which are diagnostic colors rather than retail lighting. The source direction checkbox does not invalidate a reviewed draft. Changing operation inputs does. A pending individual vector draft must be applied or discarded first.

**Apply reviewed normal retargeting** requires the reviewed proposed model hash. The backend rebuilds and requalifies that exact candidate before recording one model replacement command; mismatched reviews reject. Undo/Redo, Save/Open and normal Build retain prior source-bound model edits. A normal cannot be allocated or borrowed from another object; indices must fit existing u16 SVECTOR reference words. Unused source normals and unchanged requests produce no replacement. Complete primitive ownership, original/effective model compatibility and the existing4096-user budget remain enforced. Normal XYZ, vertex geometry, material fields, other references, packet counts and opaque bytes stay fixed.
