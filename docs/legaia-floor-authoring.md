`POST /api/floor-rectangle-review` accepts exactly `entity_id` and `rectangle`. The rectangle has `row_start`, `row_end`, `column_start`, `column_end` and `tier`; bounds are inclusive. Its response separates Retail, Current and Proposed selectors, supplies the verified sixteen signed MAN height values and source record, and marks gameplay unverified. The floor grid uses `0x4000 + row*128 + column`; the selected nibble is a height-table index, not a height in world units. Floor grid corners and biased wall rectangles are different coordinate interpretations.

`POST /api/command` with `type: apply_floor_rectangle`, the same owner/rectangle and returned `review_key` obtains a fresh Review before changing authored state. A change is one normal command. Restore retail removes selected overrides while retaining outside floor selectors and separate wall/scenery components. A normal private Build emits a source-bound MAP overlay and per-selector audit; it does not edit the MAN LUT.

To edit floors, refresh Resources, select the scene collision resource and open Edit source wall bits. Choose Edit floor tiers in that inspector, set inclusive floor bounds and an existing tier (or Restore retail selectors), then Review. Inspect proposed floor scene to compare the proposal with Current; Return to floor review restores the dialog. Apply, Save and normal Build use the same reviewed selectors. Floor selectors use unbiased native rows/corner coordinates; do not reuse wall rectangle Z extents.

Choose Pick floor selector in Scene tools and click visible source ground. The nearest corner of the visible triangle opens with the Current selector. Models in front of the ground are not picked through. Dragging orbits instead of selecting; changed camera/layout/project context cancels the pick. Review the unchanged tier to inspect its Retail/Current values, or choose another existing tier and Review before Apply. Edge-clamped outer corners target the existing last native row/column rather than inventing a selector beyond the grid.
