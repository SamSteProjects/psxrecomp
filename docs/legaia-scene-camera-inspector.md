# Numeric scene-camera inspector

Open **Camera coordinates** in the scene viewport toolbar. Read the current target X/Y/Z, camera distance, yaw and pitch in degrees, and perspective/orthographic projection. Edit these values and choose **Set viewport camera**. The tool changes the viewport camera only; it does not move entities, change imported or authored transforms, attach to the runtime, or write guest memory.

The target uses **editor display coordinates**, including display Y. It is not a source-local model vertex, retail actor placement, guest RAM address or confirmed live position. Other scene tools retain their existing source-to-display conversion. Yaw is presented in the equivalent −180° to 180° range; input accepts −360° to 360°. Target coordinates must be finite within ±1e12, distance 20 to 1e8, and pitch 0° to 90° in orthographic mode. Perspective retains the existing minimum pitch of 0.12 radians. Empty, hexadecimal, nonfinite and malformed numeric input is refused. Decimal and scientific notation are supported.

A draft is bound to project path, scene identity, scene preview/representation key and camera revision. A background camera frame or scene change withdraws Set until **Read current camera** captures a fresh baseline. Busy operations disable the tool. Setting the camera cancels viewport gestures and pending framing, synchronizes the projection selector and redraws through the existing camera renderer. There is no SDK authoring command for a transient camera change.

Open **Scene tools**, then use **Saved scene views → Save current view** to persist the camera with the existing source-bound view metadata, history and project Save/Open workflow. Recall restores the exact numeric camera alongside the existing representation, layers, grid and visibility. Camera settings do not become native game Build inputs. This feature is editor navigation; matching a game camera and confirming live coordinate identities remain separate work.
