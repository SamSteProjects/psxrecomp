# Source normal direction view

The model inspector's **Model shading** control offers the usual surface view and a source-normal diagnostic. Surface shading remains the default. The diagnostic colors the direction of existing raw TMD normal vectors; it does not reconstruct retail lighting, material shading, GTE rounding, or gameplay appearance.

Open a source-backed model, choose the source-normal view, and compare Retail with Authored. The coverage note reports qualified lit triangles, unlit triangles, invalid normal references, and zero-vector corners. Supported animation frames can use the qualified rigid-frame diagnostic described below. Other posed previews keep the control disabled and the regular surface view available.

A direction is normalized after the model transform's inverse transpose, then each component maps from −1…1 to 0…1 in RGB. Source coordinates remain object-local with Y down. The display Y reflection is part of the model transform and occurs once. The inverse transpose also handles nonuniform scaling. A zero vector, an unavailable source vector, or a singular transform receives neutral gray, with availability distinguished by qualification and coverage rather than invented directions. Unlit triangles retain no source-normal value. The diagnostic does not infer face normals from positions.

## Source and authoring contract

`preview.triangle_normals` follows emitted triangle order. Each qualified lit triangle contains three raw signed 16-bit XYZ vectors. Flat packets repeat their shared source normal across corners; Gouraud packets resolve each corner's source reference. Quads emit corners `(0,1,2)` followed by `(1,3,2)`. Normal reference words are byte offsets into the object's eight-byte SVECTOR table; only XYZ is visualized, leaving its fourth padding halfword untouched.

Qualified normal reference fields begin at packet bytes 12 for flat triangles, 20 for flat quads, 18 for Gouraud triangles, and 20 for Gouraud quads. An unaligned, out-of-range, or short packet normal operand makes that primitive's emitted triangles unavailable and adds a bounded diagnostic, while preserving its already-qualified geometry. Invalid normal table spans retain the existing structural source rejection. Normal metadata uses `status: source_unposed` and `coordinate_system: retail_tmd_object_local`.

Normal XYZ edits and existing normal-reference rewiring use the established source-bound authoring paths. Review and Apply the edit, compare Authored against Retail, then Undo/Redo or Save/Open as needed. A normal Build verifies source ownership and existing write boundaries. This display mode itself performs no authoring, package change, or runtime launch. External GLB workflow limits remain in [normal XYZ editing](legaia-model-glb-normals.md) and [normal-reference editing](legaia-model-glb-normal-references.md).

## Supported rigid-frame directions (2026-10-03)

In the individual model viewer, select **Source normal directions** while a supported clip is open. Scrubbing, Previous/Next and Play show the current frame. Translation does not affect directions. The source arrays are unchanged, and the usual surface view restores its exact pixels at the same frame. Animated model authoring and retail lighting are not enabled by this display control.

`rigidFrameNormals` first qualifies the unposed signed16 source vectors and the frame's actor-local Y-down coordinate system. Each unique source object must have one matching transform, with bounded, nonoverlapping vertex and triangle spans covering the geometry. Triangles must reference their own object's vertices. Three encoded rotation components0..4095 apply analytic Rx, then Ry, then Rz, matching the existing Python vertex-pose convention. Finite translation is required but excluded from the normal calculation. Null unlit triangles and zero vectors remain neutral. The renderer applies its display inverse transpose afterward, including one Y reflection.

Derived finite vectors use distinct `source_rigid_pose` metadata, actor-local coordinates and `sdk_analytic_rz_ry_rx` transform evidence. The raw `source_unposed` contract still requires signed16 integers and rejects posed use. A renderer update accepts normals only with this rigid qualification and identical loaded triangle ownership; validation precedes writes. Qualified updates reuse buffers. Ordinary vertex-only updates disable the diagnostic and withdraw retained normal metadata so later renderer reloads cannot reuse stale directions. A one-frame cache bounds derived normal storage; geometry and textures are not reallocated by scrubbing or mode changes.

This scope covers the individual supported clip viewer. Arbitrary static poses, assembled scene animation, unknown channel layouts, retail fixed-point rounding, native lighting and gameplay appearance remain unqualified.
