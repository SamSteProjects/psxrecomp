# Author an Inspected Native Animation Channel

In an animated model preview, expand **Inspect native animation channels**, choose a rigid object and frame, then use **Edit inspected native channel**. The existing imported or retained editor opens at that exact frame/object. Opening does not change project data. The normal editor still owns drafts, validation, Review where applicable, Apply, Undo/Redo, Save and native Build.

Imported shared scene clips route to **Edit imported animation channels**. The current authoring binding must match the inspected animation/model identity and frame/object counts before the initial selection is loaded. Shared ownership remains visible, and the existing channel command rules still apply.

Saved allocated clips route to **Edit retained animation**. A fresh source-key-qualified library response must match the inspected saved record, including its record hash, model/owner identity, counts and activation state. The retained editor then reloads its normal options and validates the selected output frame/object. The previous preview/library lifecycle is disposed before opening the channel editor; it must not reopen a competing modal.

The handoff requires the current selected imported actor, Edit mode, authoring capability and the preview's current scene source key. Reference, proposed GLB, proposed allocation/content and initial-assignment previews do not silently redirect to another clip. Unsupported previews show an unavailable reason. Their existing inspection and original-editor Return workflows remain available.

No channel values are copied or applied by this navigation. Native coordinates, angle grids, frozen donor frame mapping, shared contributors, allocation capacity and normal reviewed authoring gates remain unchanged. Gameplay verification remains deferred.
