# Static stereo envelope audition

Open **Audio → Inspect bank tables → Edit bank parameters → Tone → ADSR1/ADSR2**. The existing envelope audition qualifies Retail, Current, or reviewed Proposed envelope words and their sample bytes. Choose a supported playback mode and preview rate, or a direct SPU pitch in native Gaussian mode. Enable **Stereo voice gains**, choose **Static direct registers** in **Stereo volume mode**, then enter explicit left/right direct register words. Play uses a stereo AudioBuffer; **Save envelope preview WAV** exports 44.1kHz interleaved signed16 stereo with both register words in the filename. The separate monitor-volume slider affects playback only.

Mono remains the default, preserving the original synthesis and WAV bytes. Static stereo works after each existing mono synthesis path, including linear one pass, encoded PCM loop, qualified native ADPCM loop/one pass, and native Gaussian direct-pitch previews. Its inputs apply to a single post-envelope voice before any master-volume, other-voice, reverb, CD/XA, driver or host-mix stages. They do not infer VAB pan, instrument gain, note velocity, hardware behavior or the game's actual mix.

Each direct register is an integer from 0 through 32767. Bit15 sweep mode is refused. The raw 15-bit signed value becomes an effective signed16 gain by shifting left once: 0 mutes, 8192 gives +16384, 16383 gives +32766, 16384 gives -32768, 24576 gives -16384 and 32767 gives -2. Negative gain reverses channel phase. `floor(sample * gain / 32768)` follows the recomp's signed arithmetic right shift; one-voice output saturates to signed16. The UI displays both effective gains and rejects blank, fractional, negative or sweep-register inputs. There is no guessed unity register or program-to-voice mapping.

Gain edits and enable/disable changes stop current playback. Busy/loading/starting states lock the controls; source drift and parent disposal withdraw playback/cache ownership through the existing audition lifecycle. New tone/proposal configurations reset to mono and 16383/16383. Preview settings do not create authoring commands, change bank parameters, persist to the project or alter Build inputs. A reviewed Proposed ADSR layer still uses Current sample bytes; unreviewed drafts are excluded.

`audio-static-stereo.js` reads bounded mono PCM (at most 220500 frames), keeps input bytes immutable and returns an equally bounded interleaved stereo buffer. `encodeEnvelopeWav(bytes, channels=1)` supports one or two channels, validates whole frames and preserves the five-second frame budget. The default mono signature and bytes remain compatible. The module is registered by the SDK server; no runtime source or new authoring API is added.
