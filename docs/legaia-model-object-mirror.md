# Native whole-object mirror

Open **Model → Edit vectors → Mirror whole object**. Choose X, Y or Z and a local-origin or Current bounds-center pivot. **Preview whole object mirror** reflects all stored vertices and normals, reverses the face winding, and compares Current/Proposed geometry and source-normal directions. The proposed shape can also be inspected on a supported scene instance. Return to the vector editor requires a fresh Review before **Apply reviewed object mirror**. Changing axis, pivot, object or source withdraws the prior proposal.

The axis names refer to source-local coordinates. The vertex reflection is `v' = min + max - v` at bounds center or `v' = -v` at local origin. It keeps half-unit center planes exact without floating-point rounding. Stored normals reflect about zero and retain their length. Negating -32768 would overflow signed16 and rejects the whole operation, including when an unused stored normal carries that value. No normals and zero normals are supported where the native primitive layout is qualified. Bounds are 1..8192 vertices, at most 8192 normals, 4096 primitives and 65536 native corner fields.

A reflection reverses orientation, so native face corners 1/2 swap together. The writer carries vertex references, per-corner UV, baked RGB and Gouraud normal references with those corners. Flat RGB and flat normal owners remain at corner 0. For a quad, this reverses both `(0,1,2)` and `(1,3,2)` while keeping the same diagonal. Command/padding bytes, packet descriptors, counts, group headers, material words and all other objects remain exact. The bounded source qualifier rejects unsupported or malformed packet ownership before mutation.

The client recomputes the complete reflected vertex/normal words, then checks preview triangle orientation and the matching permutation of color, UV and reflected normal corners. It accepts the three equivalent cyclic representations of each reversed triangle. Other-object triangle data, material IDs and unsupported change kinds are refused. The server reconstructs the proposal and verifies both the inspected Current hash and reviewed proposed hash before applying through the existing model replacement command. The shared model changes for all referring instances. No new project format, authoring storage or runtime behavior is introduced.

The corner convention is shared with the existing native GLB reflection implementation. AndrewAltimit's read-only pin `d6e64c68ede25813d35db20980da82a1a025549b`, `crates/tmd/src/legaia_prims.rs`, corroborates native primitive/vertex-offset layout. Reflection is SDK authoring math; preview normals are a diagnostic, not reconstructed retail lighting or gameplay acceptance.
