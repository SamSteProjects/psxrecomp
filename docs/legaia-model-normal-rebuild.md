# Rebuild stored model normals from faces

Open **Edit model vectors**, choose an object, and expand **Rebuild stored normals from faces**. Choose **Source winding cross product** or **Reverse source winding**, then use **Preview normal rebuild**. Current/Proposed views enable the existing source-normal direction diagnostic. Review the direction before **Apply reviewed normal rebuild**; source Y points down and this operation does not establish retail lighting.

The writer uses Current native vertex positions and qualified existing lit face references. Triangles use corners (0,1,2); quads use (0,1,2) and (1,3,2), the qualified Legaia preview diagonal. Each triangle contributes its unnormalized cross product once to each distinct stored normal slot it references. Flat faces contribute to their single slot; Gouraud faces contribute to the slots of the participating corners. Contributions are therefore area weighted. Existing sharing is retained, including sharing across different vertex positions; no new smoothing groups, reference edits or normal allocations are inferred. Unlit faces contribute nothing. Unreferenced stored normals stay exact.

Each referenced slot's summed direction is normalized to encoded length 4096 and rounded to signed integer XYZ, with halfway values away from zero. Exact integer cross products, sums, square-root floors and squared half comparisons avoid floating-point ambiguity; rounded vectors need not have exactly length 4096. Reverse negates the final direction. Every degenerate lit triangle and every cancelling shared sum rejects the entire proposal. Objects without lit references or normal vectors, stale hashes, malformed reference ownership and invalid fields also refuse. Bounds are 8192 vertices, 8192 normals and 4096 primitives per selected object.

Only referenced normal XYZ words can change. All vertex words, packet operands, UVs, colors, material fields, normal references, vector padding, counts, offsets, other objects and unrelated bytes remain unchanged. Authored geometry and retargeted sharing are read from Current. Pending vector drafts must be applied or discarded first. Preview and scene preview are read-only. Input changes withdraw Apply; returning from scene preview requires a new review. Apply rechecks both inspected and proposed hashes and creates one existing model-replacement command when bytes change. Identity proposals create no history entry. Existing Undo/Redo and Save/Open retain the result.

Generic model-object preview uses operation `normal_rebuild` and exactly `values: {direction: "winding" | "reverse"}`. Reports carry current/proposed native normal words and qualified Current face references; the browser independently recomputes exact words using BigInt and checks that geometry is unchanged and changes belong only to the selected object's normals. POST `/api/model-object-normal-rebuild` accepts exactly `asset_id`, `object_index`, `direction`, `expected_sha256` and `proposed_sha256`.
