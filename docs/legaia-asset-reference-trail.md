# Explore asset references without leaving the dialog

Open **Inspect asset references** from an SDK asset Inspector. Each qualified relationship retains its existing asset button and instruction navigation, and now also offers **Explore references**. Exploration opens a fresh reference neighborhood inside the same dialog. It uses the existing source-qualified SDK API; it does not infer additional dependencies, runtime use or gameplay reachability.

**Back in references** and **Forward in references** revisit previously explored identities with fresh requests. Following another relationship after Back drops the old forward branch. The Recent reference trail shows labels and the selected stable identity, retaining at most32 entries; revisiting the current identity adds no entry. Layer/direction/search filters reset when moving to another asset. Scope changes start a new trail at the selected asset; active-scene and Project reports remain distinct.

Every response still checks the exact selected identity, source key, scope contract, node/edge bounds and relation evidence. Loading disables history movement and report actions; source changes block navigation and downloads. Superseded requests are aborted and generation-checked. Closing removes the dialog and rejects late responses. Unavailable targets retain their coverage explanations and cannot be explored. Existing Inspector/instruction navigation still closes the dialog and invokes its qualified action.

**Save full reference report** now saves the complete accepted report for the currently explored asset, including provenance, diagnostics, limits and all recorded relationships. Display filters do not trim the saved report. The trail is temporary UI state; it does not change project metadata, authored components, history or Build inputs.
