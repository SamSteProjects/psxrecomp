# Retained Animation Display Names

Open a retained animation asset and use **Editor display name → Save clip name**. **Reset clip name** removes the label and restores the structural UUID title. Names appear in the active/project asset browser, the asset heading and saved-clip selectors. Stable animation IDs remain visible; a display name does not establish a retail character, gameplay action or runtime identity.

Names are separate project metadata in the optional `animation_labels` collection, keyed by retained animation stable ID and bound to the imported scene digest. They do not modify the native record ledger, channel/model ownership, donor content, assignments or Build inputs. Identical names are allowed because labels are not identities. Duplicating a clip creates a separate UUID with its own initially absent label. Active and retired retained records can be named; unsupported or missing identities refuse. Existing projects need no migration.

The exact `set_animation_label` / `clear_animation_label` commands require the current Edit scene source and complete display-name collection key. Names are trimmed, bounded to 80 Unicode characters and reject controls and unpaired surrogates. No-op writes add no history. Commands share dirty tracking, one-step Undo/Redo and Save/Open; change review identifies individual labels. Persisted names validate source identity and retained-record existence. Reimport cannot change the bound source beneath names or their session history. Labels are excluded from native Build and scene geometry keys, while full project metadata keys still change.

The asset dialog guards project/source/name context, pending writes and Edit mode. The normal command API updates state, then the asset reopens with its new heading. Client asset records resolve labels from current project state, so Undo/Redo updates names without trusting an old catalog title. Reset clears metadata rather than renaming native content.

## Project Scope Inspector Handoff

The clip naming workflow now closes its original inspector before explicitly opening the exact current asset identity. It no longer uses a timer that can lose the reopen while whole-project discovery owns the editor's busy lock. Naming/reset continue through the existing source-bound command API; the completion callback receives a detached request and resolves one current asset. Closing during the write or changing project, scene, native source or mode suppresses the follow-up inspector. A rejected write leaves the original inspector available.
