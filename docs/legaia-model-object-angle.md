# Whole-object rotation by angle

Open **Edit model vectors**, select an object and expand **Rotate whole object by angle**. Choose source X/Y/Z, degrees from -360 to 360, and **Local origin** or **Current bounds center**. The bounds center uses every Current vertex in this object, retaining half-unit centers. Vertices rotate about that pivot; all existing stored normals rotate about zero. Source Y points down. Actor heading, scene placement and animation channels are separate.

Angles quantize to the nearest 1/4096 turn, with halves away from zero. Q30 trigonometry and integer arithmetic apply one final nearest signed16 rounding. Full revolutions are identity operations; cardinal origin rotations exactly match the existing quarter-turn tool. Zero normals remain zero. Integer rounding can slightly change vector lengths; normals are not regenerated or renormalized.

**Preview whole object angle** validates the source binding and exact local/native Current and Proposed vector words. Input changes withdraw Apply. The shared comparison offers Current/Proposed geometry and source-normal direction colors, plus scene inspection. Returning to model vectors requires a fresh preview. **Apply reviewed object angle** rechecks both the inspected model hash and proposed candidate hash and uses one existing model command. Undo/Redo and Save/Open retain existing history and persistence. Pending vector drafts must be applied or discarded first.

Only selected-object vertex and normal XYZ words can change. Padding, counts, table offsets, face references, materials, other objects and prior authored replacements remain intact. Objects require 1..8192 vertices and at most8192 existing normals; objects without normals are supported. Invalid fields, stale receipts or signed16 overflow reject the complete operation. Unchanged candidates create no history entry.

The source proposal operation is `object_rotation_angle`, with exact values `axis`, `angle_units` and `pivot`. POST `/api/model-object-angle` requires exactly `asset_id`, `object_index`, those three values, `expected_sha256` and `proposed_sha256`. Generic model-object and scene previews remain read-only. The static client helper is `/model-object-angle.js`.
