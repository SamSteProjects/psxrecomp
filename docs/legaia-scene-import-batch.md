# Reviewed Atomic Scene-Group Import

Offline checks passed — 2026-10-09. This workflow ingests retail metadata into a project; it does not establish playable or fully rendered scene acceptance.

Use **Import scene… → Read scene catalog → Add [scene] to import group** for each ready scene. The queue survives prefix/page changes for the same disc path and supports removing members or clearing the group. **Review scene group** qualifies every member, reporting exact native metadata hashes, disc identity, actor/model counts and new/unchanged/replaced status. **Import reviewed group** requalifies the whole group before publishing. Changed queue, disc path, project/navigation/history or stale reviewed inputs invalidate or refuse the operation. Closing the dialog discards the queue and cancels pending read-only Review. Import Apply uses the normal serialized editor API and remains a completed or refused project transaction.

The reusable SDK service accepts 1..16 sorted unique structural scene names, at most 64 imported project scenes and at most 32 MiB imported metadata. It clones the project, invokes the existing retail scene importer for every selected member, and uses ProjectService.import_metadata for source-build consistency, stable actor identity, authored/history/bookmark reimport guards, AssetDatabase ingestion and coherent scene validation. Any failed member leaves the live project imports/assets/disc/navigation untouched. Metadata is never substituted for missing native models or unknown fields. Apply requires an exact digest of the recomputed group Review and publishes only the qualified imports, asset database, source disc and intended navigation state.

An existing project retains its active scene and selected entity, even though staging traverses multiple scenes. Authored collections and Undo/Redo history are preserved. An empty project opens the first scene in the canonical group and selects its first actor when available. Identical same-source reimports are a no-op with no project/history change. Like existing scene import, group import changes imported project metadata rather than adding an authored Undo step; the panel explains this distinction. **Save project** writes the normal immutable imported metadata sidecars and project references; Open rebuilds the asset database from them. Imported native data stays separate from authored overrides.

The editor uses source-qualified catalog rows, not arbitrary fabricated labels. Selected row actor/model counts and disc identity must match the SDK Review exactly. A bounded decoder checks operation schema, same project/source/group, immutable flags, native metadata hashes, row count/status and preserved navigation. Read-only Review has a 1 MiB response limit and stale lifecycle guards. Queue changes withdraw Apply eligibility; no-op groups cannot Apply. Group import participates in existing animation-preview, world-map-draft and live-follow project-change gates, and clears server texture catalogs like single scene import.
