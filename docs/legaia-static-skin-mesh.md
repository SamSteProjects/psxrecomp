# Static Weighted GLB Skin Pose Import

Open a model in the Asset Database, choose **Import GLB mesh**, select a native triangle donor and upload the GLB. The file inventory identifies selected static skin records and explains that their poses will be baked into geometry. **Review mesh import** shows the resulting Current/Proposed native geometry; **Apply reviewed mesh** uses the existing source-bound receipt and one history command. Source scene, section, scale, origin, rotation, donor and allocation choices retain their existing review invalidation behavior. The original weighted GLB and its recipe remain in the model's retained mesh-input library for recovery and reimport.

This supports a static external skin pose, not native skeletal animation or retargeting. Joint node transforms at the file's declared pose and inverse-bind matrices produce per-joint world transforms. Per-vertex paired JOINTS/WEIGHTS sets blend those matrices. The skinned mesh node's transform is ignored, as required by the [glTF 2.0 skin specification](https://registry.khronos.org/glTF/specs/2.0/glTF-2.0.html#skins). Omitted inverse binds use identity. Weighted transforms apply to positions; their inverse transpose supplies normal directions. Existing unit conversion, Y reflection, native XYZ rotation/offset and signed coordinate/normal rounding follow the bake. Geometry still inherits qualified native donor packet and material ownership.

Qualification is bounded by the existing 64-node scene forest, 64 skin records and up to 64 unique joints per skin, all in the selected static scene with a common ancestor. Optional skeleton identity must be a common joint ancestor. Up to eight consecutive paired influence sets are supported, with unsigned byte/short joint indices and float or normalized unsigned byte/short weights, including interleaved vertex data. Skin POSITION tables have at most 8192 vertices; existing per-transaction native allocation limits still apply. Sparse skin influence/inverse-bind or misaligned attributes, missing pairs, bad joint indices, repeated nonzero joint ownership, nonfinite/negative weights, invalid weight sums, malformed inverse binds and singular matrices reject before mutation. Permitted weight rounding error is renormalized before applying translations.

Selected animated nodes remain unsupported. Saved dense or sparse morph targets can now bake before these skin transforms through the [static morph workflow](legaia-static-morph-mesh.md). Unselected activity remains explicitly excluded. A triangle whose vertex transforms mix reflected and non-reflected orientation is rejected; consistently reflected transforms preserve winding with the existing corner/UV/color coupling. Distinct influence accessors on primitives sharing POSITION data retain separate baked vertex ownership. No native joint tables, skin weights, animation channels, project format or runtime behavior are added. Donor normal rules remain exact: Gouraud lit triangle donors can allocate per-corner normal rows, flat lit donors require a single direction per face, and unlit donors retain their existing normal limitation.
