# NPC Transition Arrival Authoring — Integration Foundation

NPC-owned named `SCENE_CHANGE` arrival entries now participate in typed SDK source/review commands, atomic Apply/Clear, Undo/Redo, Save/Open, Current script composition and native package Build. Each clone owns its own partial or complete encoded X/Z/direction overrides; Retail donor data and other clones remain separate. Destination names, instruction length, dispatch context and unrelated bytes remain preserved. Arrival bytes describe the player's destination entry, not NPC placement or source trigger coordinates.

The Inspector exposes transition ownership alongside the nine existing script families. The existing script-reset workflow can remove owned transitions, and saved Build comparison independently qualifies their emitted one-byte spans. Dedicated arrival editing controls and portable NPC preset support are **not finished**. Preset capture currently refuses a draft with owned arrivals, preventing the legacy capture format from silently dropping them. The full feature remains in development; these boundaries are work to complete, not a reduced definition of the goal.

The source and review APIs are `/api/npc-transitions-source` and `/api/npc-transitions-review`. Apply uses `set_actor_draft_transitions` with exact `entity_id`, complete `entries` and the matching fresh `review_key`. Empty entries clear the family. Only encoded integer bytes 0–255 are accepted for `entry_x_encoded`, `entry_z_encoded` and `direction_encoded`; destination names and additional fields are refused. An inherited value is distinct from an explicit override equal to Retail. Typed identifiers bind the source donor and four-digit hexadecimal instruction PC.

Source qualification retains the existing named-transition gates, including complete known source paths and a clean scene name. Proposed inspection uses a detached draft map and the shared Current serializers. It does not mutate project history or represent generated allocation. Both compressed and streaming Build paths compose the independent native writer before branch edits; actual streaming delivery for this new project field still needs its own integration evidence.
