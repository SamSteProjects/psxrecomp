# PCM WAV sample authoring groundwork

`importer/audio_sample_authoring.py` adds a native SPU-ADPCM encoder and fixed-allocation PCM WAV replacement codec. Persistent SDK bindings, shared bank/SEQ/sample composition, editor import/preview controls and native Build delivery remain the next integration. The existing sample audition and WAV export remain source-only; this checkpoint does not make them authoring controls or establish runtime playback acceptance.

The source decoder's pinned integer evidence supplies the five predictors, signed low-nibble-first samples, predictor history, rounding, signed16 saturation and reserved-shift interpretation. The encoder searches all five predictors and shifts 0–12 for each 28-frame block with closed-loop decoded history. It chooses the trial with the lowest squared PCM error; equal errors prefer lower predictor then lower shift. Blocks are chosen greedily, rather than claiming globally optimal encoding. Native ADPCM is lossy; the audit includes squared error, maximum absolute error and the exact decoded PCM hash.

`replace_sample_wav` accepts immutable bounded Retail/Current sample bytes, their expected hashes and a bounded RIFF/WAVE file. The input must be standard mono signed16 PCM (`fmt` length 16, or 18 with zero extra format bytes), have internally consistent block/rate fields and a declared input rate of 8000–192000 Hz. Complete chunk extents, RIFF length and unique format/data chunks are checked; bounded unrelated chunks are allowed. Float, stereo, other widths, malformed/truncated/duplicate chunks and mismatched frame counts reject. The declared WAV rate remains input metadata; no native sample rate, runtime pitch, resampling, duration or instrument assignment is inferred.

The source must have a nonempty complete decoded prefix ending at its encoded end or exact sample-span boundary, within the existing 4096-block/114688-frame budget. Unknown predictors/flag bits, incomplete blocks, empty samples and a prefix stopped by the budget reject. WAV frames must exactly match that qualified prefix. Existing reserved shifts 13–15 are understood through the source decoder's effective shift 9; newly encoded output uses canonical shifts 0–12.

Every source flag byte remains exact, including loop/end bits. Bytes after the first encoded end remain opaque and unchanged. The encoder replaces only block predictor/shift and nibble payload bytes; total sample allocation, flags and trailing bytes stay source-owned. Current must preserve those boundaries, flags and trailing bytes before another edit is reviewed. Output is decoded again and must exactly match the encoder's integer PCM history and the original end boundary.

`replace_audio_sample_wav` maps one qualified sample back into standalone VAB, leading contiguous VAB or split header/sample carriers. It requires exact source entry, bank, sample and Current entry/sample hashes, a typed sample index and one physical piece owner. Everything outside that sample remains byte-identical: VAB tables/counts/parameters, other samples, SEQ chunks and physical padding. It reopens the native bank and checks exact sample readback/piece ownership. This single-family domain codec requires other Current entry bytes to remain Retail; the SDK must later isolate and compose parameter, sequence and sample families independently.

Nine focused sample/waveform Python checks passed with the retail disc configured and no skips. Fixtures cover deterministic silence/no-op, low-nibble order, extrema and independent error/PCM audits, composed Current, reserved shifts, all three carrier shapes, native sample ownership, exact outside-span preservation, malformed inputs, stale hashes and flag/tail/unknown/budget rejection. Existing waveform behavior passed unchanged.

A retail sweep inventoried all samples in the 202 qualified banks: 1694 reached an encoded end, one was empty and one exceeded the decoder budget. Each bank had an eligible sample; the first eligible sample in every bank was replaced from half-amplitude mono PCM at an explicit input rate, with independent literal-coefficient PCM decoding, exact error audit, flag/tail preservation and complete entry comparison outside the selected sample. This proves 202 sample replacements, one per bank; it does not claim that all 1694 eligible samples were encoded. All 202 retail banks use split carriers; standalone/leading carrier coverage is synthetic. The 16 unavailable source banks remain outside authoring.
