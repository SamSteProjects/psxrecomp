This is the native allocation and read-only SDK Review foundation for new World placement authoring. The grid selects both placement data and terrain tile/page/CLUT. Whole-record donor copying would change the target tile's ground appearance. Allocation therefore copies the complete donor record but preserves the target record's four terrain selector bytes at +20..23, sets explicit signed16 XYZ offsets and low-twelve-bit yaw, retains donor opaque metadata and upper yaw bits, and changes only the target cell's low-nine-bit record index. Upper cell flags, height/floor tables, all other records and unrelated bytes remain identical. Records must be unreferenced by all 16,384 current cells and entirely zero before allocation. Reserved records 0..3 are excluded. Cells anchoring existing resolved or unresolved placements are excluded from the target inventory.

Requests contain exactly `placement_id`, `donor_cell`, `target_cell`, `record_index` and `values`. The values contain exactly signed16 `offset.x/y/z` and `yaw_units` in 0..4095. One to 32 clones are bounded by the 511-placement scene budget, with distinct IDs, native records and cells. Missing donors, occupied or unsupported targets, nonzero records, aliases, out-of-range or boolean indices and extra fields fail before publication. Reopening the complete MAP must preserve every existing source seed and unresolved/excluded coverage while adding exactly the requested native seeds. Review reports distinct authored identity and the native cell-based seed identity without relabeling imported data as authored.
