# Object-wide vertex-reference retargeting

Open a model, choose **Edit model vectors**, select its object, choose **Vertices**, and select the Current vertex index. **Find faces using this vertex** reports Current and Retail stored reference words, their face/corner ownership, and source coordinates. **Inspect current face** opens that exact face in the existing primitive Inspector. Lookup changes neither project content nor history. The report binds the current model hash and project source key; stale selections, pending vector drafts and closed dialogs invalidate it. Complete lookup is bounded to4096 users; the browser displays the first128.

Expand **Retarget uses of this vertex in this object**, choose another existing **Target vertex index**, and **Preview vertex retargeting**. Every matching face corner in this object changes to that target. Current/Proposed layers share camera framing. Vertices are retained, with their original coordinates; this operation changes references rather than deleting or allocating geometry. Faces can collapse. Stored normals are not recomputed. Counts, packet layout, material fields, padding and other objects remain intact.

Preview qualifies the complete Current-user graph and checks every proposed reference change against its exact owner and requested values. Missing, duplicate or foreign changes reject. **Apply reviewed vertex retargeting** requires the reviewed whole-model candidate hash; the backend rebuilds that candidate before recording one undoable model replacement. Editing the draft invalidates the review. No-op and unused-source requests create no replacement. Object-local indices must fit existing u16 SVECTOR reference words (byte offset divided by8).
