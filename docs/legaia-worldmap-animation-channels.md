# World Native Animation Channel Inspector

Open a registered World animation clip in Project Asset Details and choose Inspect Native World Channels. The inspector exposes every supported native frame's rigid-object translation, PSX rotation and opaque nibble, with Retail and saved Current values kept separate. A compatible model or placed object is not required. Source-only clips stay source-only; the inspector does not invent skeletons, poses, timing or runtime activation.

The SDK verifies the registered clip against its retail bank and immutable source range. The editor independently checks complete Retail/Current bank hashes, source record layout and every saved channel override. Replaying the full saved binding must reproduce the entire Current bank, including neighboring records. Source-only and compatible source-instance clips share this inspection workflow.

Frame navigation is local after qualification. Invalid frames withdraw the table. Close aborts pending reads and disposes the snapshot. CSV export includes stable animation ID, layer-specific record SHA256, frame/object indices, Retail/Current translations and rotations, and opaque source data. Before export, fresh server project, Edit mode and World source key must still match. The CSV contains private decoded game data and should remain local.
