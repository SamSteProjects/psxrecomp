# Initial Model Resolution Inspector

Scene tools now offers **Inspect unresolved model references**. The read-only inspector lists every affected source actor and NPC draft in the active scene, separates Retail from Current initial model references, shows encoded indices and native pool slots, and exposes the corresponding source record. Selecting an affected entity returns to the existing scene selection/Inspector workflow. No guessed asset, model assignment or authored change is created.

`/api/model-resolution` requires the exact active scene and current asset-reference source key. It freshly verifies the imported scene against Retail, checks native model-slot ownership, qualifies effective actor donors and independently owned NPC donors, then rechecks the key. NPCs have no imported instance layer and clone their retained Retail donor independently of source appearance overrides. A reference with no enumerated model retains a null asset ID and explicit unresolved status. Reports are bounded at 8,192 entities and four MiB; overflow refuses rather than silently omitting entries. Metadata reports contain no model payloads.

The client checks report identity, counts, duplicate entities, encoded byte/pool/slot relationships, native actor/source/disc spans and resolved versus unresolved asset IDs. Scene models retain scene-local IDs; global models retain existing shared `asset://legaia/models/global-special/00f0`-style encoded IDs. Data is detached. Project/source changes withdraw the displayed result; busy/stale controls cannot select an entity. Closing aborts a pending request and removes the owned timer/dialog.
