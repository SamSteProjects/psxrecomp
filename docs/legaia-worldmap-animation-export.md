# World Animation Full-Clip GLB Export

Preview a supported Retail or saved Current clip in the World source-object Inspector, choose an explicit export fps, then Export Inspected World Clip GLB. Export saves the GLB and a separate audit JSON. Returning to normal Current geometry or entering channel editing withdraws the inspected export source. Stale project/source keys and mismatched bank/record hashes refuse export.

Both animation layers use the selected raw Current model. The output is object-local: World placement is excluded. The shared GLB exporter embeds matched textures/materials, preserves rigid object identity and emits STEP translation/quaternion tracks for every native frame. It reflects Y once and reverses winding. The last frame is held for one selected frame interval. No anatomical skin hierarchy, native timing, native looping, runtime activation or physical meter scale is claimed. Export fps is explicitly caller-selected.

The source audit records the project snapshot, scene/entity/model/clip identity, selected layer/rate, complete bank and record hashes, file hash and shared encoder audit. The browser requalifies those values and downloaded GLB header/length/hash before saving. Inspection/export is read-only and does not change commands, history, project or game. Supported scope is the five source-compatible World instances across Map01/Map02/Map03; unbound or unsupported clips have no fabricated model export. Proposed drafts are not exported by this path.
