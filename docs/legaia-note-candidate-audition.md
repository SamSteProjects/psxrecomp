# Current Note Candidate Audition

In a sequence’s operand editor, select a positive-velocity Current note and choose **Inspect Current encoded bank links**. For a listed tone with an in-range encoded sample, choose **Audition Current candidate page … record …**. The editor opens that exact tone’s ADSR inspector with **Current** selected and the encoded note key prefilled. Its caption retains the Current event index, channel and original key. The base sample rate stays blank, and audio does not play automatically.

Load the sample, choose a supported native ADPCM loop/one-pass mode and Native Gaussian preview, then select **Reference note model** and supply a base rate. You can listen to the bounded one-voice preview or save a WAV through the existing audition. The note key remains editable as a preview assumption; the caption identifies the original source note. Selecting another tone withdraws the seed. Source and Current identities stay separate throughout.

Before opening the editor, the action re-reads the exact Current note/program/bank link report and requires equality with the displayed evidence. It then freshly verifies the Retail bank hash and opens the normal bank editor, whose typed Current entry and authoring-state checks must agree with the handoff. Pending reads lock link navigation, audition and evidence download. A changed candidate or source refuses; parent close/stale ownership disposes the candidate editor and suppresses late publication. Invalid/unresolved sample operands, unavailable Retail bank identity or missing Edit capability disable the action. No Apply, Save, Build or runtime operation occurs automatically.

This selects an encoded program/key-range **candidate**. Packed-page/program ownership and active runtime instrument identity remain unconfirmed. Preview pitch uses the explicitly assumed base rate and the reference model described in [Reference Note Pitch Preview](legaia-reference-note-preview.md). Velocity, controllers, pitch bend, actual driver tuning, voice allocation, reverb and full sequence playback are not inferred. The note handoff is temporary editor metadata and does not enter project files, authored parameters or native output.
