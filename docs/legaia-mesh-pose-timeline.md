# Animation Pose Timeline

In **Import GLB mesh**, choose the original GLB, enable **Sample animation pose**, choose a named clip and use **Inspect animation pose**. Qualified selected-scene channels now expose their time range, a slider, **Stage range start/end** and a **Sampled channel ranges** inspector with node, path, key count, interpolation and first/last time.

The navigation range is the union of sampled channels in the selected source scene. Excluded channels are not decoded and do not define it. This is not a claim about the full clip duration, native animation timing or playback. A constant single-key range disables the slider while retaining endpoint navigation. Empty selected-channel sets, another selected clip and unqualified geometry hide navigation.

Slider and endpoint navigation change only the numeric draft time. They withdraw Review/Apply without sampling or mutating the project. Use **Inspect animation pose** to qualify that time, then Review. Numeric times outside the channel range remain exact; the importer clamps each channel to its own endpoints. The slider displays the nearest range endpoint without overwriting the numeric draft. Pending operations and stale project context disable navigation. Native commands, original-source retention, pose recipes and Build formats are unchanged.
