# Saved World Inspection Views

In **World ground**, inspect a kingdom and open **Saved world views**. Enter a name and choose **Save world view** to retain the camera, Retail/Current layer, model display, instance scope, selected source entity or retained authored decoration and wireframe display. Creating a view selects its new entry. **Rename**, **Replace**, **Recall** and **Delete** operate on that selection. Views are listed for the loaded kingdom.

Recall freshly qualifies the native kingdom, selected entity, asset and complete source instance membership before restoring the display. A Current view also requires qualified imported-disc placement context. A changed source, stale project/view key, missing instance or changed display during qualification refuses recall. Loading the requested layer must succeed before the saved camera and selection are applied. This does not restore a historical authored placement snapshot: Current uses the project's current authored placements.

Views use the existing project saved-view collection, typed commands, dirty tracking, Undo/Redo and Save/Open. The shared limit is 128 field and World views. Each World record is bounded to 128 KiB, with a 16 KiB source record and at most 512 asset instance identities. Rename and Delete require Edit mode but can work without the disc. Retail views can be created in disc-backed empty projects. Field saved-view lists and counts exclude World records, and field commands reject them.

These are editor display settings. They do not change imported provenance, authored native transforms, Build inputs, export scope or runtime state. Source spawn seeds do not establish runtime visibility or resting positions.

## Authored Decoration Targets — 2026-10-10

A retained decoration selected in Current can be saved as a World view target. Proposed previews cannot be saved or recalled as retained views. The authored binding holds the placement UUID, native cell identity, record index and model pool index, plus immutable Retail kingdom/model provenance. It deliberately excludes mutable XYZ/yaw, donor lineage and candidate record hashes. Editing the target's XYZ/yaw or rebasing its donor after deletion therefore preserves the view. Moving its native cell changes ownership and refuses recall. Recalling restores the exact saved camera; it does not move the target or automatically recenter the camera on its new position.

Authored views retain only their selected target identity in `source_instance_ids`. The selected-asset display scope resolves the current same-model group on recall, including any newly retained decorations, rather than restoring historical scene membership. Original Retail-target bindings keep their existing complete source-instance membership guard. Existing saved records need no migration.

Recall can start from Retail: native Current placement/model receipts are independently replayed without altering the display, then the Current layer is qualified before camera, selection and scope are restored. Missing/deleted targets refuse before a layer switch. Undoing deletion makes the saved UUID target available again. A changed native cell/record/model owner or source provenance still refuses. Rename/Delete remain available for metadata maintenance even when the target is missing.

Nine actual native reviews across Map01, Map02 and Map03 cover initial, moved and donor-rebased targets with current model growth and original-transform coauthors. Target deletion refuses without mutation, Undo restores recall, and Save/Open preserves metadata. An [unreviewed decoration translation](legaia-worldmap-placement-allocation.md#authored-decoration-viewport-translation--2026-10-10) also disables World view Save, Replace and Recall. Native Review or Discard clears the local render override; a saved view cannot silently persist or omit that temporary draft.

[Unreviewed yaw or combined XYZ/yaw poses](legaia-worldmap-placement-allocation.md#authored-decoration-viewport-yaw--2026-10-10) use the same saved-view guard as translation drafts. Native Review and Discard clear the separate affine display override; Recall cannot silently discard or persist an unreviewed rotation.
