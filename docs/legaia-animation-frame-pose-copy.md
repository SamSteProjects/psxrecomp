# Complete Native Frame Pose Copying

Open a retained animation from the project Asset Database, choose **Edit retained content**, and select the source **Allocated frame index**. In **Frame sequence tools**, set the destination output range, choose **Complete rigid frame** under **Pose copy scope**, then **Stage effective pose copy**. Review, preview the textured Proposed pose, return, Apply and Save. Existing Undo/Redo, Save/Open and normal Build consume the retained-record edit command.

Complete-frame copying snapshots the effective source pose for every existing native rigid object before modifying any destination. It includes inherited donor channels and draft overrides. Each destination receives all six axes for every object while retaining its opaque channel bits, output-to-donor mapping and record layout. Frames outside the range and the frozen donor capture remain unchanged. Source-inside-range and one-frame identity copying are supported. This preserves the clip's existing object identities; it does not retarget another rig, author a new skeleton, infer playback timing or modify unknown metadata.

**Selected rigid object** remains the default and keeps the existing v1 staging receipt. Explicit boolean `all_objects=true` requests the v2 complete-frame receipt, including object count, ordered source poses and every frame/object before/after pose. The client checks scope, complete object identity, native channel grids, source/destination authored values and exact proposed draft rows. Invalid scope flags, omitted/reordered poses, changed objects, forged edits and mismatched v1/v2 scope reject. Changing the UI scope withdraws Review; pending/stale guards remain in the existing editor. Staging is read-only and fresh Review precedes Apply.
