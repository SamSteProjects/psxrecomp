# Build Stability Source Evidence

Normal Build now retains the recorded SDK stability source comparison in `build-audit.json` under `validation.runtime_source_inclusion`. **Review Build** displays the proposed evidence and includes it in the complete review download. **Build history → Verify saved files and open report** displays the evidence retained with that saved package, rather than checking the current checkout and attributing it to an older Build.

The `legaia.build-stability-source.v1` receipt is deterministic metadata. It retains the recorded checkpoint and historical release-reference revisions, execution-evidence date and comparison-receipt hash, plus every recorded relative path, category, expected hash, actual hash and comparison status. `checked_at` is excluded: unchanged inputs and source evidence keep the same audit and package identity. The normal audit hash and completion receipt bind this metadata to the saved package manifest/version and ZIP hash. It is retained in the audit beside the package, not introduced as a runtime payload inside the ZIP.

Source comparison starts before serialization, repeats before audit identity is finalized, and repeats after packing before a completion receipt is saved. A changed comparison during either phase rejects completion. An existing checkpoint mismatch or unavailable source is retained explicitly and is not misreported as matching; source inclusion is descriptive evidence and does not replace content serialization validation. Saved verification validates the receipt shape, paths, comparison consistency, summary and false execution/binary/gameplay claims. Legacy packages without the field remain readable and display their missing evidence explicitly.

This is Build-host recorded source inclusion only. It does not establish the executable used to run a package, an installed or attached runtime, all release patches, a fresh stability fixture run, or gameplay behavior. No runtime/precompile implementation changes are included. Current recorded inclusion covers five runtime/precompile source files and three fixture sources; all eight match the retained checkpoint.
