# Retail Scene Preview Before Import

The scene catalog now opens a read-only 3D preview before adding a supported scene to the current Project. Orbit, zoom and Frame scene use the existing scene renderer and camera services. Import previewed scene is an explicit, separate action. Placement-only catalog entries retain their refusal reason and cannot open a full scene preview.

The SDK verifies the disc and imports native metadata into a temporary, isolated ProjectService. A fresh ScenePreviewService resolves supported models, initial poses, textures, terrain and environment content through existing SDK importers. It never replaces the user's active Project or mixes its authored overrides into this Retail view. Temporary resources are disposed on completion. The v1 report binds the exact Project source key, verified disc identity, scene identity and metadata digest; the response is bounded to 64 MiB. Live mode and changed source keys refuse preview.

The editor validates that envelope and the existing scene graph, including unique geometry/entity keys, finite transforms, renderable references, metric totals and absence of authored state. Existing renderer limits remain 128 geometries and 2,048 instances. Source changes withdraw the canvas and disable Import; closing aborts pending requests and disposes WebGL resources, observers and timers. Framing uses eight aggregate bounding-box corners rather than exceeding the camera point limit on larger scenes. No saved Project migration is required.

Actual private Retail Taiku preview rendered 290 source instances with zero unavailable instances or renderer failures: 36 actors and 254 environment instances, 127 geometries, 16,771 triangles and 1,935 terrain cells. Previewing it from a saved Taiku2 Project excluded the existing authored NPC without changing that NPC, the active scene, assets, imports, document or history. These figures qualify this specific supported scene, not arbitrary runtime scene completeness.

Actual editor checks passed orbit, zoom, Frame, stale-view withdrawal and explicit Import. Import retained the existing Taiku2 import and authored NPC; Save/Open matched and Redo remained empty. Wide and 400 px captures were inspected without horizontal dialog overflow or page errors. Browser/server helpers closed. Source placement, initial pose and texture interpretation retain the existing limitations; runtime activation, script-driven movement and gameplay-coordinate parity remain unverified. This is an editor browsing workflow with offline checks passed, not gameplay acceptance. The full SDK goal remains active.

## Retail Instance Hierarchy and Inspector

The preview now lists every native instance, including unavailable instances, and filters by stable identity, source name or model identity. Selecting an instance opens a read-only inspector; clicking actual rendered geometry synchronizes that selection with the hierarchy. Frame selected instance uses that instance's bounds. Camera drags beyond four pixels orbit without selecting. Unsupported instances remain inspectable but cannot be framed as rendered geometry.

The inspector exposes stable identity, structural kind/name, model identity, renderability, pose, Retail position, editor display position and preview-height qualification separately. Expandable provenance includes the native source record and interpretation limits. For Taiku actor 0001, Retail Y remains null while display Y is zero and height status remains unresolved_no_source_surface. This does not turn the editor ground-plane convention into a native coordinate. Inspected data is detached; foreign instance IDs refuse.
