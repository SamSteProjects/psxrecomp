## Search Saved Placements

The member browser now filters by current SDK label or stable placement ID, case-insensitively, without changing saved membership. Known actor/NPC names come from project metadata; an unknown label uses the structural ID suffix. Search is bounded to 200 characters, results retain saved canonical order, and pages remain bounded to 16 rows. The matching count distinguishes visible results from the complete group. An empty match shows a message and disables page navigation.

## Frame Recalled Placements

Saved-group and individual-member recall now offer **Frame recalled placements**. It is enabled when the dialog opens; uncheck it to retain the current camera exactly. Recall completes the normal source review and loads current geometry before fitting the selected meshes. It does not change placement coordinates, camera angles, projection, scene visibility or native game data.

Group framing now uses the existing aspect-aware `sceneFrameCamera` fitter instead of a bounding-box diagonal distance heuristic. It fits Current mesh corners with ten percent screen padding on each edge, preserving camera angles/projection. Unique bounded placement IDs and complete available mesh bounds are required; missing or invalid bounds leave the camera unchanged and show an error. The same framing path is used by existing mixed-placement-group tools and the main Frame selected action. Hidden objects and occluding scenery are not automatically revealed or removed; camera framing is not a gameplay visibility or coordinate-parity claim.

## Unified Actor and Scenery Group Framing
