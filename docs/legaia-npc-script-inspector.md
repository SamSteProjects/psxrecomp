# NPC script ownership Inspector

Select an authored NPC in the hierarchy or viewport. The SDK-driven **NPC script
ownership** component shows its retail donor script identity, complete authored
draft SHA-256 and owned target counts for dialogue, waits, movement, facing,
flags, branches, model selectors and effect colors. Expand a family's details to
inspect its authored binding. Zero means no NPC-owned overrides in that family;
it does not count retail instructions or prove runtime execution.

Ten script actions now use the shared component action adapter and SDK
descriptors. Their existing reviewed source tools and command/history semantics
are preserved. Buttons form a vertical stack in the narrow Inspector. Capability,
Edit mode, busy, exact selection and authored/source freshness are checked at
dispatch; donor and saved-Build inspection remain read-only actions.

Asset Details now includes effect colors. Its previously declared branches,
flags and model-selector actions are registered too. The dedicated source tools
still qualify retail instructions independently. Donor identity and authored
counts are project metadata, while generated bytes require the saved Build
comparison. Runtime binding remains explicitly unasserted. Other NPC authoring
forms retain their existing adapters; the overall inspector migration is partial.

Offline acceptance (2026-10-06): 35 affected Python checks passed with no skips,
four affected client suites and three editor syntax checks passed. A real private
Town0b editor showed two independently color-edited NPC snapshots, each with one
owned color target and zero other owned families. All eight authoring source
routes returned 200 through real button clicks; donor and saved-Build Inspector
actions opened. Asset Details opened effect-color editing and exposed branches,
flags and model selectors. Detached adapter checks passed fresh dispatch and
busy/Edit/capability/selection/source refusal, while retaining read-only donor
inspection. Wide and 400 px screenshots were inspected. Project document,
history, scene and selection were unchanged; no game requests or page errors.

The initial browser capture omitted the mobile Inspector tab; a later click
check found the new group used a dialog row layout and clipped its buttons.
The final vertical Inspector stack and mobile-tab workflow supersede those
retained failed attempts. This UI/metadata change required no new native Build or
gameplay verification. Full regression campaigns were not rerun.
