# Animation Argument Usage Inspector

The Animation Script Arguments panel now offers **Find Matching Animation Argument Sets**. It searches the active scene's source-qualified P1 actors, P2 scripts and NPC drafts for the selected instruction's saved effective numeric argument set. Local unsaved drafts are excluded. Results distinguish **Retail match** from **Effective match**, retain the instruction PC and encoded context, and open the matching source or NPC argument editor.

Matching numbers establish neither model/clip identity nor shared behavior. Instructions may be unvisited in the current authored branch flow. Runtime activation, timing, valid argument combinations and gameplay remain unknown; the inspector does not infer a clip binding or access runtime memory.

`/api/animation-operand-uses` requires `entity_id`, `animation_operand_id` and `expected_state_key`, with optional integer `offset` (default zero). Offset must be a multiple of 256 below 8,192 and identify an existing result page. Other fields and invalid offsets refuse the query. The SDK checks active-scene ownership and the current authored-state key, loads verified native source targets once, validates each retained override against the native writer, and keeps NPC values independent from donor-source overrides. Inspection is read-only and rechecks the key before returning. Unknown/unqualified source instructions remain excluded; unresolved authored entries refuse the query rather than disappearing.

The scan is bounded at 8,192 qualified sites. The `legaia.animation-operand-uses.v2` response returns at most 256 matching rows per page, with `page_offset`, `page_size`, the full match count and explicit truncation. Previous/Next controls make every match within that bound accessible, in deterministic source-owner/instruction then NPC-owner/instruction order. The client checks the exact requested page and row count, independently qualifies native bytes and match flags, refuses duplicates and returns detached data. Each row retains donor ownership, source record hash, native widths/dispatch and Retail/authored/effective arguments. State changes withdraw results. Navigation reopens the existing source-qualified editor; it does not apply a change. No saved Project migration is needed.
