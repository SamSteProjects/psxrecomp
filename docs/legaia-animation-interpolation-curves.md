# Native Animation Interpolation Curves

Open a retained animation asset, choose **Edit retained content**, expand **Frame sequence tools** and choose **Native interpolation curve**. Linear is the default. Ease in accelerates from the first endpoint; Ease out slows toward the last; Smoothstep eases at both ends. The curve applies to **Interpolate authored endpoint axes** and **Stage effective pose interpolation**, including the Complete rigid frame scope. The imported-channel editor also provides these curves, as described below.

Authored-axis interpolation replaces only the matching explicit endpoint axes for the selected rigid object. Effective interpolation samples all six inherited-plus-authored native axes for the selected object or every object in the complete frame. Select distinct output endpoints, stage, then use **Review retained edit**, optional **Preview reviewed content**, and **Apply reviewed content**. Changing the curve withdraws an existing review. The curve selector follows the same pending, source and disposal guards as the retained editor.

Curves modify sampled poses over the existing output frame range. They do not retime the clip, infer cadence, perform quaternion interpolation or change actor world placement. Native translations keep signed twelve-bit limits and half ties toward the larger integer. Rotations keep shortest per-axis paths, positive half-turn ties, sixteen-unit quantization and modulo4096 wrapping. Endpoints, outside frames/objects, frozen donor mapping, opaque nibbles and native metadata retain their existing ownership boundaries.

The backend and client use exact integer ratios: progress is t for Linear, t² for Ease in, 2t−t² for Ease out, and t²(3−2t) for Smoothstep. With at most 512 output frames, integer intermediates remain exact in the client. HTTP staging accepts the optional typed `curve` field (`linear`, `ease_in`, `ease_out`, `smoothstep`). Omission preserves legacy Linear receipts v1/v2; curved selected-object/complete-frame receipts use v3/v4 and bind the requested curve. Clients independently validate all expected sample words and the complete resulting edit set. Only sampled channel edits enter the existing project format; no new runtime or persistent curve field is introduced.

Gameplay appearance and cadence remain deferred; the full SDK goal stays active.

## Imported Channel Workflow

Select an imported actor with a qualified native clip and choose **Author animation channels**. Copy a verified Retail or Effective channel, select the target endpoint pose on the same rigid object, set **First target frame** and **Last target frame**, choose **Interpolation curve**, then **Review interpolated frame range**. The proposal identifies the curve and lists its complete native samples. **Apply reviewed interpolation** uses the existing source-bound `set_animation_channels` command and creates one history action. Changing the curve clears Review; changing any source, pose, range or authored state still rejects the held proposal. Shared-clip conflict/capacity checks remain in the existing writer.

Both imported and retained sampled-range tools now use the same exact native-grid curve helper. Imported ranges retain the existing 4096-channel budget; retained clips retain their stricter 512-frame/4096-channel budget. The unchanged fractional-axis helper remains available to its existing consumers. Native playback timing and interpolation in the game are not inferred.

Programmatic close on ordinary successful Apply still permits the normal refreshed-editor workflow. Cancel listeners are released at close. Long native sample lines wrap inside the imported dialog at narrow widths.

## Reviewed Channel Pose Preview

Scrub stored frames, inspect native channel graphs or orbit the character. The proposal is labeled **not applied**, uses [Current model geometry](legaia-current-model-animation-preview.md) and static texture associations, and retains approximate rigid/GTE viewing limits. It incorporates qualified authored model content and does not establish native playback timing. The clip selector identifies the reviewed proposal and cannot switch to another clip; shape authoring and applied-animation exports are unavailable in this inspection.

Close the model viewer to return to the same channel draft. **Inspect animation in scene** projects the proposal into the existing scene inspector with the existing placement/height conventions. **Return to channel review** restores the same reviewed draft and Apply action. The scene projection does not verify live coordinates or actor height/facing. Scope, curve, endpoints or source changes invalidate the held proposal. User Close during a pending preview prevents a late response from opening the viewer. Cancel ownership is rearmed when returning from scene inspection.

## Reviewed Channel Range Removal

Choose the inclusive First/Last target frames and Selected rigid object or All rigid objects, then choose the axes to remove: all six, Translation XYZ, Rotation XYZ, or a single translation/rotation axis. This removes only the selected actor's stored contributions; unselected axes, objects, frames and other shared owners remain. A frame can retain partial contributions after removal. No matching contribution produces a message without an Apply action.

Review lists the stored axes proposed for removal without changing the project. Preview shows the resulting effective clip with Current geometry, including any retained shared contributions, and returns to the same review. Apply uses one normal channel command; removing the actor's final contribution uses the existing clear command. Source, range, object scope and axis changes invalidate the prepared action.
