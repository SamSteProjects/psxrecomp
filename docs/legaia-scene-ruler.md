# Scene vertex ruler

In the scene viewport, choose **Measure mesh vertices**, then **Pick A** and **Pick B**. Click a visible Current triangle near a corner. The ruler snaps to the nearest projected corner of that depth-tested triangle within 24 CSS pixels, with the lower decoded vertex index resolving equal distances. It does not select an entity or move a transform. A missed pick remains pending; zoom or choose a nearer corner. **Cancel pick** or Escape withdraws pending picking. A drag orbits the camera without choosing a vertex.

A and B markers and a dashed line appear in the viewport. The panel shows decoded model XYZ, editor display XYZ, B-minus-A and straight-line distance in display units. Distance is visible above the scrollable coordinate details. Orbit, pan and viewport resizing keep completed points because their world coordinates do not change. The line is an editor overlay and can appear through scenery. It does not measure a collision path, terrain route or real-world unit scale.

Coordinates come from the currently loaded SDK preview vertices and the same per-instance matrix and position override used by rendering. The display Y reflection is included exactly once. A decoded index identifies the preview vertex, not an invented native SVECTOR or guest RAM address. Instance transforms may include derived preview height or an explicitly qualified pose; absent native actor height remains unknown. Model, entity, geometry, triangle and decoded vertex identities, decoded point, instance matrix and display point are retained in evidence. These are editor geometry facts, not confirmed gameplay coordinates or runtime identity.

The tool is available for Current authored geometry in Edit mode. Competing face/floor/history/runtime/script picking, transform drafts, group/proposal layers and unsupported/loading scenes disable picking and withdraw measurements. Scene/project/source/representation or hidden-entity changes invalidate points. Camera changes retain points but camera/size changes during a click reject that gesture. The ruler owns left clicks while pending; existing face/floor/arrival transform tools cannot consume the same pick.

**Download measurement** produces `legaia.scene-vertex-measurement.v1` JSON with the complete snapshot context, both endpoints, exact finite display delta/distance and stated limitations. Before publishing it, the editor reads fresh `/api/state` and rechecks project path, scene and source key. An authoritative mismatch withdraws points and disables reuse until the Current scene is refreshed. Close, clear or context changes while the read is pending cancel the export. The module also checks ownership synchronously at pick/export boundaries. No authored command is generated. Session points are cleared on reload and are not saved into the project or named views.
