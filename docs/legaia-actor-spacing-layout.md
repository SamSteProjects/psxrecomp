# Actor Group Spacing and Reflection

Select two through 128 imported actors in the active scene and open **Actor group placements**. Choose **Scale X/Z spacing around anchor**, **Reflect X positions about anchor**, or **Reflect Z positions about anchor**, then select an actor in the group as the anchor. Preview lists separate Retail, Authored, Effective and Proposed coordinates. **Inspect group in scene** supplies the existing Current/Proposed comparison, Frame, Return and Restore workflow. Apply replays the reviewed source and creates one atomic history command; Save/Open and Undo/Redo retain the authored coordinates.

Spacing percentages are whole numbers from 1 through 1000. Scaling changes positions about the selected anchor and rounds final coordinates to the nearest 64 native units, with halfway values away from zero. Rounding can put actors at the same position. Reflection changes one X/Z coordinate about the anchor. The anchor stays fixed. Neither operation scales or reflects mesh geometry or changes source height, facing, appearance, scripts or scheduling. Native coordinates must remain on the 64-unit grid from 64 through 16384; an invalid member rejects the whole proposal before project mutation. A 100-percent scale is a no-op and adds no history. Changed controls withdraw the prior Review and comparison.
